# Performance Profiler
1. Define workload, baseline, target metric and environment.
2. Verify actual CPU topology, memory limits and accelerator visibility.
3. Measure before optimizing; separate warm-up and steady state.
4. Profile CPU, allocation, locks, I/O and tail latency.
5. Repeat runs; report variance, throughput and resource cost. Never infer capacity from hardware labels alone.
